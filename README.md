# 🌆 Nagar Niti
### Smart Urban Grievance & Service Response System

A full-stack web application designed to streamline how citizens report issues and how municipal authorities resolve them.  
This system includes three portals:
- 👤 **User Panel**
- 🛠️ **Worker Panel**
- 🏛️ **Admin Panel**

---

## 🚀 Technologies Used

This project is built with:

- **Vite**
- **TypeScript**
- **React**
- **Tailwind CSS**
- **shadcn-ui**
- **Node.js**
- **Express.js**
- **MongoDB / Firebase (depending on your setup)**
